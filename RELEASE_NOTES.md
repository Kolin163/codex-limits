## Codex Limits for macOS

Download **Codex-Limits-macOS-arm64.zip**, unzip it, and move **Codex Limits.app** to Applications.

- Apple Silicon (M1 or later), macOS 13+.
- Requires Codex Desktop installed in /Applications or ~/Applications and a saved ChatGPT login. A separate CLI installation is not required for supported Desktop layouts.
- Remaining quota in the menu bar; quota windows, reset dates, and countdown on click.
- Teal above 60%, yellow at 25–60%, red below 25%.
- System time zone, automatic refresh, manual refresh, and last-update age.

This community utility is not affiliated with OpenAI. It is ad-hoc signed, not Apple-notarized. macOS may show an unidentified-developer warning; see the README for Apple's instructions. Desktop internals can change, and some authentication configurations may not share a session.

SHA256SUMS.txt contains the archive checksum. Source archives listed below are for developers; most users want the application ZIP above.
